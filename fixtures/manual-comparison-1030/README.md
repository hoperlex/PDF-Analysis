# Ручная проверка сравнений

Распакуйте `comparison-manual-pack.zip`; в интерфейс загружайте **внутренние ZIP**.

| Модуль | Что загрузить | Что проверить |
|---|---|---|
| Сравнение версий | `VS1-five-versions.zip` через «Импорт ZIP с версиями» | Порядок v1→v5 и четыре соседних перехода. |
| Сравнение стадий | `SP1-OLD.zip` как П, `SP1-NEW.zip` как Р | Пара П→Р; на вкладке 2 сохраните карту листов перед запуском. |
| Графика (отдельно) | `SP1-NEW-graphic-derivative.zip` вместо обычного NEW | В R2 добавлена окружность. |

Все документы синтетические. Результаты ИИ в комплект не входят.
