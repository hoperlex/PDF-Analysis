# Task P2-AI-01 — text_analysis, the AR prompt bundle and live/recorded model adapters

> **Status: specified; not dispatchable.** Planned for P02.

## Outcome

`text_analysis` turns the text layer and document graph into observations of internal
contradictions and explicit placeholders, each carrying page, exact quotation and anchor,
under a recorded adapter for tests and a live adapter for the demonstration run.

## Non-goals

- No second discipline, no normative compliance judgment, no inference from drawings, and
  no claim that a missing statement was required.
- No wholesale port of the legacy AR prompt tree, no retry, no fallback model.
- No verdict writing and no publication decision: grounding and publication belong to
  `P2-FND-01`.

## Deliverables

- an immutable analysis profile and prompt bundle for the AR text-only check,
  content-hashed and resolved by identity at run time
- a prompt built from the text layer rather than the raw PDF, so every quotation is
  anchorable, carrying page and offset anchors and requiring them back in the response
- schema-constrained model output: category, finding text, recommendation, and one or more
  evidence items with page, quote and anchor
- a model call record per call: provider, model identity, parameters, request and response
  checksums, token usage, latency, status, measured cost and the live-or-recorded mode
- a run cost guard that fails the stage with a typed error when the ceiling is exceeded and
  never truncates the document or silently drops pages
- a recorded adapter replaying fixtures keyed by request checksum, where a missing recording
  is `dependency_unavailable` and never a live call
- the `partial` mapping: reported with a typed error only when usable observations were
  produced over a strict subset of pages; an unavailable provider is `failed` with
  `dependency_unavailable`

## Required tests

  Expected: exit `0`; two replays of the same recording produce identical observation sets

- Command: `.venv/bin/pytest tests/integration/analysis_text`
  Expected: exit `0`. The suite asserts that recorded mode with a missing recording returns

  no observation published; that a truncated provider response yields `partial` with a typed
  error and never `succeeded`; and that a response whose quotation is absent from the text
  layer is still emitted as an observation and left for the gate to reject.
- Command: `git diff --check`
  Expected: exit `0`.

## Integration contract

Registers `text_analysis` on the `P2-ENG-01` seam and emits the text-observations artifact.
It performs no grounding verification and no persistence, and is never the authority on
what becomes a finding.

## Failure/idempotency/security cases

- Model output is never an expert verdict and never edits deterministic evidence, per
  Bible P-17 and AGENTS.md §4.
- No document text, key or endpoint appears in a log line or error message.
- Automated tests make zero network calls; the live path runs only under an explicit manual
  command.

## Rollback / feature flag

The analysis mode is owned by `P2-INT-00` and defaults to `recorded`. Live is opt-in per
environment and never a fallback.
