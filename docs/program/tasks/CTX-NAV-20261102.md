## Integration contract

`scripts/docs_context.py` reads the checkout at invocation time. `index` writes only to an
explicit caller path; `search` and `show` are read-only. JSONL rows locate source lines
but confer no authority. The process policy changes future acceptance and release
delegation; this task has no authority to update a remote ref.

## Failure / idempotency / security cases

- Invalid or out-of-range `show` addresses fail, rather than reading outside `docs/`.
- Repeated indexing of an unchanged tree is byte-identical.
- Code-fence text is not interpreted as a Markdown heading.

## Rollback / feature flag

Revert the task paths to remove the optional navigation tool and entry links; there is
no runtime feature flag or data migration.
