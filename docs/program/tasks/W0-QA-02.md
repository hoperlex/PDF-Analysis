## Integration contract

Exit `0` plus standalone `PASS` means real schema machinery ran over every
repository-owned candidate and all structural gates completed. Expected repository
defects return `1` with accumulated artifact/check diagnostics; missing/unusable
schema machinery returns `2`. Neither path emits traceback or `PASS`.

Current ADR files may grow beyond 18 only when each new unique ADR is indexed. The
original ADR-0001–ADR-0018 baseline may not be removed or substituted.

## Failure/idempotency/security cases

- Git discovery failure is an actionable gate failure, not a broad filesystem scan.
- Ignored/private/generated content is never opened or counted.
- Malformed inputs cannot abort later independent checks; diagnostics remain
  sanitized and identify artifact plus invariant.
- Repeated runs are read-only and produce equivalent results for one repository
  state; tests create only isolated temporary repositories.

## Rollback / feature flag

No feature flag or bypass. Revert only this task's validator/test/README commit if it
regresses the CLI contract; dependency lock and contracts remain untouched.
