# Task P2-BHV-01 — deterministic AR corpus and seeded-issue oracle

> **Status: specified; not dispatchable.** Planned for P02.

## Outcome

A regenerable synthetic Russian AR PDF with exactly two cross-page contradictions and one
explicit placeholder, plus a negative-input corpus, so every other lane tests against one
fixture instead of inventing its own.

## Non-goals

- No scanned or OCR corpus, no ZIP or companion inputs, no second discipline, and no real
  or customer document.
- No expectation of model wording: the oracle names issues, not sentences.

## Deliverables

- a baseline Russian AR PDF within the envelope, containing two seeded cross-page
  contradictions, one literal placeholder and clean control statements that must not be
  flagged
- a byte-deterministic generator with fixed creation date and font subset and no random
  identifiers, with the recorded SHA-256 of every output
- an expected-issues manifest recording, per seeded issue, the category, both page numbers,
  the exact expected quotation substrings, and the control statements that would be false
  positives if reported
- a negative corpus: image-only, encrypted, oversize, over-page-count, non-PDF and
  companion-archive inputs
- a README stating that this corpus is synthetic and is the only PC-01 acceptance input

## Required tests

- Command: `.venv/bin/python tools/fixtures/build_ar_corpus.py --check`
  Expected: exit `0`; regenerated bytes match the recorded SHA-256 for every fixture.
- Command: `.venv/bin/pytest tests/contract/fixtures_ar`
  Expected: exit `0`; asserts the page count, size and per-page embedded text of the
  baseline, and that each negative fixture violates exactly the envelope rule it is named
  for.
- Command: `git diff --check`
  Expected: exit `0`.

## Integration contract

Ingest, analysis, findings and QA consume these paths read-only and never add a second AR
fixture. The expected-issues manifest is the only source of PC-01 seeded-issue truth.

## Failure/idempotency/security cases

- Regeneration is byte-identical; a drifting generator fails its own check before any lane
  consumes it.
- The corpus is synthetic; no customer or production payload enters Git.

## Rollback / feature flag

Not applicable: test data only.
