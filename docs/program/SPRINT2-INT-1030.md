## Согласие, стоимость и восстановление

Для **нового** обычного v3 Run оценка включает `coverage_version=batched-v1` и отдельные конечные лимиты вызовов на окно:

- Анализ блоков:2.
- Комплексный анализ:4.
- Нормативная сверка:8.
- Критик:8.
- Корректор:8.

Итого максимум30 дополнительных вызовов на окно; отсутствие входов/целей не расходует вызов. Основной текстовый анализ учитывается отдельно. Оценка резервирует расширенный объём до старта; согласованный денежный потолок и проверка перед каждым реальным вызовом остаются обязательными. Это верхняя оценка, а не уже понесённые расходы.

Пакеты имеют устойчивые ключи и SHA входа, источники, диапазоны текста, состояния и причины остатка. Сохранённый ответ используется повторно. Неопределённый исход платного эффекта запрещает новые вызовы. Один пакет не может незаметно превратиться в дополнительные оплаченные запросы сверх принятого лимита.

Принятая старая команда не приобретает новый бюджет. Изменение SHA реализации старого v3 может остановить ожидающий запуск до нового вызова и потребовать свежего согласия; исторический SHA не подделывается. Для нового согласия `AUDITMANAGER_EXTENDED_COVERAGE=legacy` оставляет прежний лимит шести дополнительных вызовов на окно; `AUDITMANAGER_EXTENDED_ANALYSIS_PLAN=v2` сохраняет прежний полный v2; `AUDITMANAGER_EXTENDED_ANALYSIS=0` отключает расширение новых запусков.

Обычный анализ по-прежнему выбирает весь принятый комплект в пределах загрузчика: до500 страниц PDF или1000 portal IMAGE, максимум63 окна по16 изображений. Новые контекстные/пакетные пределы могут оставить явно помеченный остаток. OCR не добавлен.

## Граница V3 сравнения стадий

Отчёт V3 не расширяет сам native-текстовый исполнитель до полного графического оригинала. Его пределы16 страниц /80000 символов /400 фрагментов сохранены. Простое увеличение до64 страниц было бы неверным: общий `make_plan` ограничивает закодированный payload240000 символами, Mapper имеет отдельные региональные ограничения, а разбор полностью непарных страниц ограничен своими пакетами. Нужен отдельный механизм планирования, а не замена одной константы.

Новый каталог источников содержит реальные закреплённые native-фрагменты и покрытие страниц, включая прогон без событий. Навигация использует существующие авторизованные evidence-действия. Дополнительных модельных вызовов ради отчёта нет. Ранее сохранённый прогон без новых метаданных остаётся читаемым с явно отсутствующим каталогом, а не с восстановленными наугад данными.

## Показ на презентации

Это инструкция оператору, **не выполненный прогон**.

1. Использовать API/worker/web этого кандидата и синтетические комплекты другой сессии.
2. Для анализа раздела создать новый Run со свежей оценкой и достаточным согласием. В расширенном анализе показать пакеты, диапазоны текста, фактический охват и остаток.
3. Найти замечание через поиск/фильтры, открыть его реальный источник, показать исходник и отдельный исправленный кандидат. Выгрузить полные данные независимо от текущего фильтра.
4. При необходимости скачать ZIP с отчётами и исходными PDF. Доступ и размер каждого PDF проверяются через существующие авторизованные чтения; размер и SHA сверяются с метаданными неизменяемой версии. Полный архив создаётся только при наличии всех обязательных файлов; отдельные выгрузки остаются доступны независимо.
5. Для сравнения стадий выбрать отдельный экспериментальный native V3, выполнить существующие prerequisites и обычные согласия на вызовы. Показать параметры и их независимые статусы, источники, покрытие и технический XLSX/HTML/JSON/CSV. Для этого маршрута брать комплект в пределах его явно указанных ограничений.
