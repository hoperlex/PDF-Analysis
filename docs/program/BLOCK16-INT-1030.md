# Шестнадцатый блок: точные места предварительных наблюдений

База `origin/dev=f6e19de7f1a547a23f138346c8c22c700f28dc14`, API1.14.0/migration0044. Task `BLOCK16-INT-1030`, root единственный автор, dev /owner deploys.

В прежнем saved-result matcher одинаковые текст/хэш фрагмента одной страницы могли совпасть при разных character_start/end или разных распознанных записях. Кроме того, точные source_evidence цитаты самого наблюдения не участвовали в ключе. Новый read-only ключ сохраняет исходное поле native/recognised text, полные диапазоны, entry ordinal, page-text/artifact SHA и роль артефакта вместе с физической страницей/координатами.

Сохранённые цитаты наблюдения разрешаются через реальный каталог источников, а не локальный ID другого прогона. При наличии диапазона проверяются целочисленные Unicode-границы/длина цитаты, принадлежность исходному фрагменту и совпадение literal quote, если полный текст этого фрагмента передан. Страница/поле/номер распознанной записи не могут противоречить каталогу. Отдельно участвуют все первичные evidence anchors без случайного порядка evidence_ordinal, с сохранением кратности. Разные места/цитаты остаются отдельными; некорректная или непривязанная запись не получает точного соответствия.

Исторические записи без source_evidence не получают придуманных цитат; доступные реально привязанные сведения остаются в точном ключе. Все исходники/IDs сохранены, похожие или иначе привязанные наблюдения могут остаться односторонними. UI и ограничения JSON/CSV/HTML объясняют это правило. Новых полей API/сохранённых наблюдений, модельных запросов, source extraction, экспертных решений и identity carryover нет.

Изменены только saved-results model/report/UI существующего stage-comparison widget и программные документы. Backend/paid helpers, API/contracts/generated, migration0044, routers/composition root, dependencies/locks, global styles, tests/fixtures и синтетика не затронуты. Публикация — normal clean dev push/read-back с сохранением incoming commits; deployment остаётся за владельцем.

**UNVERIFIED:** никакие tests/build/compile/import/typecheck/lint/browser/DB/model проверки не запускались. Точное сопоставление одинаковых цитат в разных местах страницы, Unicode ranges, OCR entry identity, конфликтующих/неполных каталогов, первичных цитат/повторов и экспортов требует D-290.
