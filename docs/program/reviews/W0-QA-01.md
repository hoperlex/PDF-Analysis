## 6. The residue that is not a machine guarantee

**Re-pointing a legacy stage name from one existing canonical stage to another existing
canonical stage passes every referential-integrity check in this family, and this review
does not and cannot claim otherwise.** Every reference stays resolvable, the identifier
sets are unchanged, no stage is orphaned, and Gates A, B, C and D all stay green. It is
a **semantic** change, and it belongs to semantic review — the `PD-02` reviewer reading
the 62 recorded `rationale` strings, and, where the meaning of a stage boundary moves,
the repository owner — not to a machine gate.

`AnalysisReferentialIntegrityTests.test_remapping_a_name_to_another_existing_stage_stays_resolvable`
asserts the residue exists rather than pretending it is closed: it performs such a remap
in memory and confirms that everything still resolves. Detecting it mechanically would
mean restating all 62 name→stage pairs inside the gate, i.e. duplicating the artifact
under check as a second normative mapping table, which this task's non-goals forbid.
`contracts/analysis/v1/README.md` states the same residue, and
`W0.3_ratification_integration.md` records that a later remap is a semantic change even
if referential-integrity gates pass. All three statements agree; this report adds no
fourth.

## 8. Limitations of this verification

1. **Scope.** The `ACCEPT` covers `reviewed_candidate_commit` and the artifact hashes in
   section 2 and nothing else. Any later contract, architecture, golden or validator
   change voids it and requires rerunning the affected positive and mutation checks.
2. **`schema_version` is still live under `fixtures/golden/**`.** Eight files carry it:
   the five journey manifests, `selection.json`, `journey-manifest.schema.json` and
   `selection.schema.json`. This is **outside** `ID-01` and `ALR-24`, both of which are
   scoped to `contracts/**` (`ALR-24.scope == ["contracts/**/*.json"]`), and the golden
   family self-declares as fixture-local. Stated as a cross-family fact rather than a
   defect: **three contract families version themselves under `contract_version`; the
   golden baseline versions itself under `schema_version`.** A consumer that assumes one
   version key across the whole repository is wrong. The test module pins the exact
   eight-file list and the `ALR-24` scope it rests on, so a silent move in either
   direction fails.
3. **No committed automated gate rejects a reintroduced domain `version` key.**
   `scripts/validate_bootstrap.py` requires `contract_version` and *tolerates* an extra
   `version` beside it — `test_error_catalog_accepts_deprecated_version_mirror_beside_canonical_key`
   in the existing validator suite asserts that it stays green — and it never validates
   the three domain catalogs against their own schemas. Mutation 7 is caught only by the
   domain README's family gate, the event README's recursive sweep, and the owning
   schema. Until this evidence commit, none of the three was wired into an automated
   suite. This is expected, not a defect: `ALR-24` says explicitly that it is a
   specification for `W1-ARC-01` and makes no compliance claim at CP-00. Recorded so
   nobody reads a green `validate_bootstrap.py` as `ALR-24` enforcement.
4. **The name→stage judgment is out of reach**, as section 6 states in full.
5. **`fixtures/golden/SELECTION.md` §8 invokes bare `python3`**, not the pinned
   `.venv/bootstrap/bin/python` that every other documented gate names. Its three
   commands use only the standard library, so both interpreters produce the same result
   here, and both were confirmed to resolve to Python 3.12.3 in this environment. It is
   a reproducibility hazard on a host whose `python3` is older, not a defect in the data.
6. **Gate B depends on a legacy checkout being present** at
   `/root/projects/PDF-proverka/PDF-proverka`. It reads only immutable Git objects at
   `32b9d903792b30506048a1d42b0e6b2d07aee403` and never the mutable working checkout,
   but on a host without that path the gate cannot run — and the test module fails
   rather than skipping, which is the intended behaviour.
7. **Byte identity needs the candidate commit to be reachable.** On a shallow or
   history-truncated clone the integrity test fails loudly. That is correct: it cannot
   certify a tree it cannot compare.
8. **Deferred inputs stay deferred.** `U-04`, `OQ-02` and `OQ-04` remain open with their
   recorded later deadlines. No numeric retention, tenant, IdP, lease, retry or cost
   value was invented, checked or implied. This review makes no product assertion and
   duplicates none of the 62 name-resolution decisions as a second normative table.
9. **Manual acceptance is not in scope.** The six cases of
   `docs/manual-tests/CP-00_architecture.md` are the independent manual tester's, and
   `W0-INT-01` gates on them separately.
10. **This report contains no payload body, credential, environment dump or legacy
    source content.** Legacy evidence appears only as commit-pinned locator counts.
