## 0. The question

`W28-LIVE` measured a failed run in a browser and found the screen honest and well built,
with one hole: **it prints an identifier where every neighbouring line is a sentence.**

> **The run terminated `failed`. Nothing was published.**
> **Terminal reason: `dependency_unavailable`**

The boundary this task sets is the whole of its difficulty. `dependency_unavailable` says
a dependency was unavailable; it does **not** say which. In `recorded` mode the true cause
is a missing recording while the provider is fine. `W27-REFUSE` found nginx `413`
rendering as *"The upload did not reach the API."* — true, and misleading. **A sentence
that names the wrong cause is worse than an identifier that names none.**
