# W57A-INT-SET-ARTIFACT-PREP-01 — retrieval set and catalogue preparation

## Result

`norms/retrieval/artifact.py` renders canonical UTF-8 JSON bytes with a SHA-256
digest for one W57a retrieval set. The set binds the reviewed map digest,
`ns_`, reviewed content key, embedding build, builder version, snapshot
content digest and the exact ranking prompt part. Its rebinding part contains
the full reliable text of every mapped document, including reliable paragraphs
that were not selected for the prompt. The builder checks the map's canonical
bytes and item/document identities, dense prompt labels, selected row content,
source text digests, NFC, and complete canonical ordinal input.

`norms/retrieval/catalogue.py` renders a deterministic catalogue of every
caller-supplied snapshot document, retaining the SQL-generated
`designation_tokens` as input data. It checks the independent snapshot
document count, duplicate identities and slugs, NFC and required fields.

## Contracts and limits

No API/domain/analysis contract, migration, root dependency, composition,
provider, custody or runtime interface changed. The map's canonical JSON
must contain `reviewed_content_key`, `norms_snapshot_id`, `embedding_build`,
`mapped_document_ids` and ordered `items` with unique `id`. This is the pure
builder's input contract for later MAP-01 review; it does not assert that a
map was reviewed, a snapshot is qualified, a catalogue query was complete or
the generated bytes have verified custody. The caller must obtain those
facts from the promotion database and custody workflow. No production corpus
content was read or committed.
