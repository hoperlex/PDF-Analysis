# Тринадцатый блок: журнал нормативного поиска

База `origin/dev=679a0dc91de8f74ceb199942b5e456efcf7f0f3b`, API1.14.0/migration0044. Task `BLOCK13-INT-1030`, root единственный автор, dev /owner deploys.

Раньше `_norms` удаляла предложенные norm_queries после поиска, а результат не сохранял причину отказа каждого запроса, использование локального кэша и наличие непрочитанной выдачи. Поэтому «кандидат не найден» нельзя было проследить до фактического поискового действия. Новый отдельный `norm_lookup_receipts` сохраняет исходные запросы рядом с результатом анализа, с ID/ordinal наблюдения, его source IDs, scope окна/глобального прохода и фактическим snapshot.

Для каждого уже рассматриваемого запроса записаны нормализованный cache key, выполнение/кэш/отказ, реальное число полученных hits и их document/paragraph IDs, обозначения/пункты/страницы, SHA/размер переданной цитаты и признак её сокращения. `has_more` означает только непрочитанное продолжение полученной страницы. Первые3 hits и общее поисковое окно1000 не объявляются исчерпывающим поиском. Нет корпуса, запрос не предложен, запрос вне окна, ошибка и действительный ответ без попаданий остаются разными случаями. Повторный поисковый проход имеет собственный ordinal; исходные записи не склеиваются.

Это перенос полезной формы ручного продолжения original missing_norms_queue, не внешний intake и не утверждение отсутствия нормативного документа. Успешный поиск не подтверждает актуальность/применимость кандидата. UI по25 квитанций с поиском/фильтром показывает исходные запросы, ссылки на реальные документы и записи, требующие ручного разбора по доступности/сокращению выдачи. Отсутствующий исторический журнал не реконструируется; пустой новый журнал не считается завершённой нормативной проверкой.

MD/HTML/JSON сохраняют все квитанции независимо от фильтра; новый лист `NormLookups` технического XLSX содержит полные последовательные JSON-части. Новая метаинформация хранится отдельно от наблюдений и paid payloads, поэтому не меняет request/source hashes модели, расход, schema/allowlist или сохранённые ответы. Поиск/таймаут/кэш/пределы не расширены; дополнительных SQL/search/model запросов, каталоговых записей и экспертных действий нет.

Изменены только `runs/extended_review.py`, новый/существующий extended-review UI, audit-run report/XLSX и программные документы. API/contracts/generated, migration0044, norms queries/public seam, frozen analysis/norm-context/parameter helpers, routers/composition root, dependencies/locks, global styles, tests/fixtures и синтетика не затронуты. Публикация — normal clean dev push/read-back с сохранением incoming commits; деплой остаётся за владельцем.

**UNVERIFIED:** никакие tests/build/compile/import/typecheck/lint/browser/DB/model проверки не запускались. Capture/cache/error/first-page/tail behavior, source/window identity, повторные попытки и отсутствие изменения paid payloads, ресурсные границы больших журналов, UI и экспорты остаются D-290. Журнал отражает только фактически сохранённые поисковые действия и не доказывает полноту нормативного охвата.
