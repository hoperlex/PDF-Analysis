# Четвёртый блок: свод стадий и большие спецификации

Продолжение `SPRINT3-INT-1030`, база `origin/dev=6e2eb23b`. Владелец разрешил последовательные кодовые блоки и публикацию в `origin/dev` без отдельных подтверждений; развёртывание выполняет сам. Это **непроверенный разработческий кандидат**: тесты, сборка, компиляция/import, lint/typecheck, браузер, worker/DB и модельные прогоны не выполнялись. Синтетические комплекты другой сессии не изменялись.

## Совместимость и переключатели

`AUDITMANAGER_STAGE_V3_PLAN=windowed-v1|legacy` выбирает прежний план для новых стартов; по умолчанию новый `windowed-global-v1`. Согласие на следующий модельный вызов сохраняется. Принятый bundle не подменяется: изменение исходного кода может потребовать новый запуск до нового расхода; история и сохранённые ответы остаются доступны.

Для новых обычных запусков `AUDITMANAGER_EXTENDED_COVERAGE=batched-fixed-v1` выбирает прежний фиксированный бюджет 30 дополнительных вызовов на окно; `legacy` сохраняет прежний шестишаговый бюджет. Default `batched-v1` закрепляет рассчитанный по источнику комплексный лимит. Увеличение действующего согласия задним числом запрещено. Верхняя оценка большого metered-плана может потребовать большего согласованного бюджета или быть отклонена до начала.

## Интеграционный контракт

API 1.14.0, 233 paths / 259 operations / 620 schemas, migration `0043_stage_ai_generations` не меняются. Новые внутренние сведения используют существующие JSON-проекции. Общие слоты AI jobs и EstimatePanel принадлежат интегратору; прочие области разделены задачами `BLOCK4-STAGE-1030`, `BLOCK4-SPEC-1030`, `BLOCK4-EXPERIENCE-1030`.

Не затронуты `contracts/**`, migrations, root dependencies/locks, global styles, composition root, `tests/**`, `fixtures/**`. Публикация только `origin/dev`; `origin/main` и deployment не входят в задачу. При входящих изменениях владельца интегратор сохраняет их перед обычной fast-forward публикацией и записывает точный SHA в локальный handoff. Все проверки кандидата остаются в D-290.
