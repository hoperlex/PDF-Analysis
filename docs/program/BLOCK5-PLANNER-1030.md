# BLOCK5-PLANNER-1030 — source handback

Чистый планировщик выбирает до8 пар настоящих текстовых фрагментов разных 16-страничных окон. Native-страница и отдельная распознанная запись сохраняют разные роли/артефакты, SHA страницы/записи/фрагмента и точные диапазоны Unicode code points. Размер переданного фрагмента — до20000 символов. Индекс использует буквальные марки, предметные слова и единицы как сигнал отбора, не как доказательство расхождения.

Границы: до20000 записей источника,4096 фрагментов /8000000 индексируемых символов,2000000 символов на одну запись,32000000 символов для хэширования исходных записей; до16384 терминов,96 терминов на фрагмент,32 postings на термин,40000 link events и2048 известных кандидатов. Очередь/отбор распределяют источники между окнами/каналами; это ограниченный индекс, не полный all-pairs поиск. До128 примеров оставшихся пар/пропусков; полные счётчики, digest пропусков и признаки сокращения сохраняются отдельно. Изменившиеся локальные модельные наблюдения не входят в идентичность полного текстового источника.

Публичный seam plan_global_cross_window лениво предоставляет чистую функцию. Runtime связывает реальные SHA подготовленных артефактов и включает реализацию в rules bundle. Никаких DB/storage/provider эффектов в планировщике нет.

Изменённые области: src/auditmanager/analysis/extended/cross_window.py; этот отчёт. Exact grant — соответствующий task, а завершение интегратором — tasks/BLOCK5-INT-1030.md, раздел Integration takeover.
