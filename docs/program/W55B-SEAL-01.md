### Readings where the plan was silent

1. **The busy refusal is `dependency_unavailable` / `upload_capacity`**, not a new code: its catalog entry is `503` and
   retryable already, and W55A took the same route for the norms stubs.
2. **`analysis_input_budget_exceeded` is `422` / `policy`**, not `409`: the request is well formed and the document is
   what is too large for today's configuration; `cost_budget_exceeded` (`409`) is a different fact (money spent during a run).
3. **`portal_block_id` is not in `identifiers`**: that map is every prefix-ULID identity this product mints, and the
   uniqueness check and `id_pattern` read it; a 32-hex external value there would be a false statement.
4. **`recognised_text.flags` is an open lowercase snake_case vocabulary**, not an enum: RECOGNISED measures which flags
   exist and cannot reopen the contract.
5. **`geometry` is per block**, repeating its page's check, so a block never has to be joined to a page to know it has
   no crop; `status` is a token pattern, not an enum, because only `recognized` and `failed` have been seen.
6. **`geometry.crop_image` is in the registry because the plan names it**, which made the seam register's
   table require a body for it: `test_seam_register.py` now allows a two-digit section (`4.10`) and an `ArtifactRef`
   example (`"role"`) for a blob role.
7. **The "twenty-three-code" / "23-code" prose and `116` / `52` / `45` literals** in the swept files were re-measured,
   not replaced blindly: of the 54 operations 39 declare their own `422`, 15 declare none and 51 require a credential.

## 4. Risks and known limitations

- **Contract and implementation disagree until `W55B-INGEST-01`** — by the plan's own staging: the contract says ZIP,
  500 pages / 250 MiB and a bare-PDF refusal; the running service still accepts a bare PDF up to 30 pages / 25 MiB.
  The browser's envelope constants (30 / 25 / `application/pdf`) are INGEST's; the two web tests that read the contract
  text now assert the bundle's sentences, and the constants they pin are untouched.
- **`rendered-language.guard.test.ts`.** `PortalBlockType` publishes a bare `text`, so the guard's
  `text_analysis → ['text', 'analysis']` expectation became `['analysis']`. The proper fix — add `PortalBlockType` and
  `PortalGeometryState` to `TRANSLATED_SCHEMAS` with `SCHEMA_MARKERS` — cannot be done here: the matrix would then demand
  a screen that renders them. **`W55B-WEB-BLOCKS` must do it**, or a raw `text` / `image` / `stamp` on a screen is
  not flagged.
- **Stage and artifact versions are unchanged** although a stage's inputs and outputs widened and the crop manifest
  gained content. Nothing consumes either yet; `W55B-RECOGNISED-01` and `W55B-GEOMETRY-01` own the stage code and cannot
  edit the registry, so a bump would be a `W55B-FIX` decision.
- **`listVersionPortalBlocks` loads the whole ordered list** through the port and pages in the router (the pattern of
  `listDocuments`); at 500 pages that is hundreds to a few thousand blocks. A cursor that locates a key is O(n) per page.
- **No memory peak was measured** for this lane (`W55-PLAN.md` §C5 asks the full-gate lanes for one): it changes no
  memory-sensitive path. STREAM and INGEST measure the upload peaks.
- **The schema inventory was resealed from three counts against the DDL and eight untouched digests**, not from a
  row-by-row diff against a second database at `0020`.
- `tests/contract/test_cp00_candidate.py`, `test_cp00_final_state.py` and `test_validate_bootstrap.py` were not run
  (they fail in any linked worktree for environmental reasons, per the brief). `scripts/validate_bootstrap.py` reads only
  `identifiers`, so the new map is not checked for prefix collisions; `blk` collides with nothing.
- The host is overloaded (load average 28–44, `MemAvailable` 1.1–2.6 GiB for the first ninety minutes of this lane). The DB
  steps waited for ≥ 3 GiB and ran when it was 5.5 GiB.
