# Девятый блок: готовность СО и неполный результат

База `origin/dev=c5cfc04e5e33a380b57741eccc13d9d3dd116912`, API1.14.0/migration0044, task `BLOCK9-INT-1030`. Root единственный автор; только dev, owner deploys.

При отсутствии comparison/job строки существующее чтение СО уже умеет собрать сравнение из сохранённых совместимых ответов. Теперь оно также возвращает честный read-only `incomplete` diagnostic, если обнаружен конкретный непрочитанный/неполный источник или непроверенный сохранённый ответ. Готовый текст, которому ещё нужен модельный разбор (`SPEC_NOT_READ`), остаётся `not_started`: холодный вход не объявляется ошибкой извлечения.

Диагностика не создаёт job/строку сравнения, не запускает модель/рендерер, не записывает решения и не переписывает историю. Известная причина блокирующей стороны выбирается до сравнения; добавления/удаления не выводятся. Настоящие coverage/extraction IDs сохраняются; неизвестные coverage и totals **не сериализуются как null или фиктивные нули**. Completed free view сохраняет прежний путь; incomplete не приписывается выполненная фаза done.

UI объясняет существующие SPEC_* причины по-русски, показывает чтение готовности без нового задания и даёт read-only обновление. Пустой список incomplete больше не означает «изменений нет». `not_applicable` подписан «Полные СО не определены», с явной границей чтения сканов/неподготовленных страниц. Технический код доступен отдельно. Закрытые wire поля/причины не расширялись; платные планы, source keys и журналы не менялись.

Изменены только `comparison/specification/service.py`, `web/.../version-series/ui/specification-panel.tsx` и программные документы. Contracts/API/generated, routers/composition root, migrations, зависимости/locks, global styles, tests/fixtures, синтетика и paid runtime не затронуты.

**UNVERIFIED:** без тестов/build/compile/import/typecheck/lint/browser/DB/model проверок по указанию владельца. Не подтверждены все ветки ready/incomplete/cached/no-source в реальном HTTP/UI и производительность чтения. Это готовность текущей native-СО-проекции, не OCR/экспертная полнота; существующая классификация страниц остаётся отдельной границей. Приёмка D-290 открыта.
