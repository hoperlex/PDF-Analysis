### Readings where the plan was silent (conservative choices)

1. **History identity.** A history row carries an `audit_event_id` (`evt`): a designation is an
   appended audit event, the catalog already declares that identity, and a new identity would
   need `shared/identity/ids.py`, which is outside this grant. The cursor stays a sort key, never
   a sequence.
2. **Actor without a foreign key.** `actor_user_uid` is a format-checked `usr_` value, not an FK
   to `app_user`: an FK would need an `access/references.py` entry (outside the grant) and would
   block purging an administrator who once designated. It is history, not a reference.
3. **`setCurrentNormSnapshot` takes no `Idempotency-Key`.** It is a compare-and-set on
   `expected_current`; an already-current target replays, a stale one is `409`. P02 §7 records
   what a repeat does.
4. **`listNormSnapshots` is any-role** (plan §A3.6, task text, `R-80`), although CD-18 calls it
   "admin"; only the history and the setter are `admin`.
5. **Attribution (NORM-Q04):** `source_attribution` on every hit and document, and once per page
   on `listNormParagraphs` (`PAGE_AGGREGATES`). `NormDocument.content_available` says whether a
   confirmed binding serves the PDF.
6. **Clause index.** Added `ix_norm_paragraph_clause` so `W55A-SEARCH-01`, which owns no
   migration, can serve the dotted-segment prefix without scanning a snapshot.
7. **The fold** maps both cases of every Latin letter that has a Cyrillic homoglyph in either
   case (`A B C E H K M O P T X Y`) to the Cyrillic lower case, other Latin capitals to their
   own lower case, Cyrillic capitals to lower case and `Ё/ё` to `е`. Latin `P` folds to `р`, so
   `CP 54` is not `СП 54` (asserted).
8. The prose guard read digits up to two places; the schema count is now 116, so
   `test_surface_counts_in_prose.py` reads up to three (otherwise it is blind to "116 schemas").
