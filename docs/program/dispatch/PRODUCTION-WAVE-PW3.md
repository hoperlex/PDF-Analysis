## Lane G — `SECTION-PROMPT-TOKEN-GUARD-01` (`D-224`)

Branch `agent/section-prompt-token-guard-01`, worktree `.local/worktrees/section-prompt-token-guard-01`.
Result: one repository test that, for each of the 14 section packages, extracts from `system_prompt.md` every **whole token** that has a digit, a Latin letter, is an all-capital Cyrillic abbreviation of two or more letters, or is a hyphenated code, and requires that token to be in (a) the union of the section's five pinned legacy files (`/root/projects/PDF-proverka` at the commit in `profile.json`, hash-verified), or (b) the v1 prompt `src/auditmanager/analysis/text/prompt.py`, or (c) an explicit allowlist file `tests/unit/analysis/text_profiles/prompt_token_allowlist.json` with a reason per token and section. The allowlist is seeded from the judge's findings of 2026-10-26 (see `SECTION-REVIEW-LEDGER-01.md` and the lane reports: `ИТР`, `ГПЗУ`, `КМ` in AI, `PE-проводника`, `000` from «0,000» in GP, PB's `123-ФЗ`/`13130`, plain acronyms) — each entry names the report that disclosed it; the lane **adds nothing it did not find by running the audit**, and prints the full list. The legacy repository is absent on some hosts: then the legacy-dependent part skips **with an explicit reason string** and a second part that always runs (allowlist hygiene: every entry still appears in its prompt, no duplicate, every entry has a reason, no class designation or norm number may be added to the allowlist without a field `class: "a"` and a justification) keeps the guard honest. Mutation proofs: insert a class designation / cable marking / norm number into one prompt → red; remove an allowlist entry → red; a substring-only match must not pass (`LS` inside `FRLS`).
Allowed paths: `tests/unit/analysis/text_profiles/**` (new test and allowlist), the two docs deliverables. Forbidden: every prompt, `profile.json`, recordings, `src/**`. If the audit finds a token that is neither sourced nor disclosed, do not edit the prompt: list it in the report as a finding (the integrator decides).
