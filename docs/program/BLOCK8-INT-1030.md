# Восьмой блок: полный каталог страниц для СО

База `origin/dev=2b987c842c4eb4fc57252b144578f52afc41299f`, API1.14.0, migration0044_section_stats_uncapped. Task `BLOCK8-INT-1030`; root единственный активный автор, публикация dev, deploy выполняет владелец.

После owner-хотфикса загрузчик допускает документы больше500 страниц. В спецификациях оставалось чтение одной страницы каталога `list_profiles(limit=500)` с игнорированием `more`; такой префикс мог стать якобы полной СО. Исправление проходит все keyset-страницы метаданных. Проверяются version/algorithm/profile identity, строгий рост физических страниц, повторы и отсутствие прогресса. Перечисление не открывает все PDF/profile архивы; чтение полных профилей использует тот же корректный обход.

Поток СО сопоставляет каталог с настоящим page_count источника, без создания огромного массива отсутствующих номеров. Недостающие/не готовые профили, известная нечитаемая страница СО или скан с неподтверждённой классификацией оставляют источник неполным. Реальные refs/номера страниц сохраняются. Whole-spec preparation и детерминированное сравнение используют существующее поведение `SPEC_NOT_READ`/отсутствия подтверждённых изменений; неполный набор не порождает фиктивные удалённые позиции.

Остаточный500-page отказ в VersionPairReader согласован с представлением `page_count` в БД после0044: положительный signed32-bit integer. Это не дополнительная прикладная квота и не снятие остальных правил идентичности/классификации/порядка/источника. Новые формы API, миграции, модельные бюджеты и промпты не создаются. Фактическое изменение набора СО меняет source/content keys; существующие estimate/accepted-plan guards продолжают требовать свежего согласия при изменении входов, без скрытого увеличения оплаченных вызовов.

Изменены `comparison/version_reader.py`, `comparison/profile/reader.py`, `comparison/specification/{reader,transition}.py` и программные документы. Frozen contracts/generated, routers/composition root, migrations, зависимости/locks, global styles, tests/fixtures и синтетика не затронуты. Исторические сохранённые результаты не переписывались.

**UNVERIFIED:** тесты/build/compile/import/typecheck/lint/browser/DB/model проверки не выполнялись. Не подтверждены реальное исполнение с501+ страницами, конкурирующее профилирование, классификация сканов, HTTP/UI и производительность. Консервативный отказ на неизвестном скане может требовать готового текстового источника/классификации; OCR этим блоком не добавлен. Все эти проверки остаются в D-290. Полный обход метаданных сам по себе не доказывает смысловую полноту анализа.
