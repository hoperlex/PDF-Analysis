# Package manifest

Пакет состоит из четырёх слоёв:

1. **Product/behavior** — что продукт обязан делать и что извлечено из legacy.
2. **Architecture** — Bible, ADR, domain/contracts, repository boundaries.
3. **Program execution** — roadmap, waves, checkpoints, version freeze, integration rules.
4. **Repository skeleton** — каталоги будущего backend/frontend/contracts/db/infra/tests/fixtures.

`BOOTSTRAP_VALIDATION.md` содержит результаты машинной проверки самого пакета перед передачей.
