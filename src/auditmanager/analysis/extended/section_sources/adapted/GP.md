# GP — Генеральный план

Посадка объектов, оси, границы, отметки, проезды/площадки, планировочные решения, благоустройство и баланс территории. Сверяй площади/проценты/отметки, план/таблицы/экспликации и видимую трассировку; нормативные расстояния без актуальных оснований только как вопросы для поиска.

Переданные границы окна, качество изображения, неполные источники и отсутствие актуальной нормы остаются явными ограничениями. Любой вывод связывается с source_ids.
