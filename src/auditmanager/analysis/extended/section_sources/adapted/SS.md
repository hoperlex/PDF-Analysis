# SS — Слаботочные системы

Состав систем, топологии, адреса/линии/устройства, питание/резервирование и кабельные журналы. Сверяй видимые датчики/приборы/шлейфы, маркировки, количества и связь схем с планами/таблицами; пожарные алгоритмы оценивай только по реально переданному описанию.

Переданные границы окна, качество изображения, неполные источники и отсутствие актуальной нормы остаются явными ограничениями. Любой вывод связывается с source_ids.
