# TX — Технологические решения

Технологическая последовательность, состав и размещение оборудования, потоки сырья/продукции/людей, производительность и ведомости. Сверяй марки/мощности/габариты/количества, проходы и обслуживаемость по переданным видам; межраздельные нагрузки только при наличии смежных данных.

Переданные границы окна, качество изображения, неполные источники и отсутствие актуальной нормы остаются явными ограничениями. Любой вывод связывается с source_ids.
