# PT — Противопожарный водопровод

Пожарный водопровод, схемы зон, узлы, насосы, баки, арматура и пожарные краны. Сверяй расходы/напоры/количества и марки между расчётами, планами, схемами и спецификациями. Каталог ВК адаптирован только для чтения водяных сетей; предметный checklist ПТ имеет приоритет.

Переданные границы окна, качество изображения, неполные источники и отсутствие актуальной нормы остаются явными ограничениями. Любой вывод связывается с source_ids.
